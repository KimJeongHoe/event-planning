# 화면 밖 「확인 필요」 장부(자동 생성, 2026-11-05)

사장님 화면에는 덜 만든 표시를 내지 않는다. 화면은 안전한 쪽(하지 않기·미리 물어보기·꼭 지킬 조건)만 보여 주고, 미확인 쟁점은 여기와 법 근거 파일 status에만 둔다. 질의 문안: docs/질의문안_판10_목록.md(제출은 하지 않음).

## 2. 화면 도구에서 뺀 쟁점(3건)

- 경품을 시가로 얼마로 볼지, 지급명세서 제출 기한은 세무사에게 확인
- 배민 「리뷰관리정책」 세부 기준(사장님광장 막힘)·쿠팡이츠·요기요 리뷰 정책(원문 접속 거부) — 배민·네이버 운영정책 원문에는 리뷰 이벤트·별점 조건을 직접 정한 문구가 없음
- 앱별 할인 부담·정산 방식(앱 계약서·정산 내역으로 확인)
