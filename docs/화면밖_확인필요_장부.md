## 2. 화면 도구에서 뺀 쟁점 (3건, preview/plus7.js의 CONFIRM 문장 — 화면에는 나오지 않음)

- 경품을 시가로 얼마로 볼지, 지급명세서 제출 기한은 세무사에게 확인
- 배민 「리뷰관리정책」 세부 기준(사장님광장 막힘)·쿠팡이츠·요기요 리뷰 정책(원문 접속 거부) — 배민·네이버 운영정책 원문에는 리뷰 이벤트·별점 조건을 직접 정한 문구가 없음
- 앱별 할인 부담·정산 방식(앱 계약서·정산 내역으로 확인)
