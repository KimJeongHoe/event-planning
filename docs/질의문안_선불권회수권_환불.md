# 질의 문안(초안) — 동네 가게 선불권·회수권 환불 기준 (제출 여부는 사용자 결정)

받는 기관: 공정거래위원회(약관심사과·소비자정책국), 참고: 한국소비자원 — 공정위 누리집(ftc.go.kr)은 이 작업 환경에서 열리지 않음

## 제목
음식점·카페·미용실이 파는 '10회 이용권'(회수권)·금액 선불권의 미사용분 환불과 유효기간 기준 문의

## 질의 내용
1. 동네 가게가 "커피 10잔 쿠폰(9잔 값)", "커트 5회권", "5만원 충전 선불권"을 종이·도장 카드로 팔고, 그 가게에서만 쓰게 합니다.
2. 확인한 원문
   - 「약관의 규제에 관한 법률」 제6조·제9조: 고객에게 부당하게 불리하거나 해지·원상회복을 막는 조항은 무효가 될 수 있음.
   - 「소비자분쟁해결기준」 [별표 2] 상품권(④-1): 명칭·형태와 관계없이 금액이나 물품·용역 수량이 적힌 무기명증표, 권면금액의 60%(1만원 초과)·80%(1만원 이하) 이상 사용 시 잔액 현금 환급, 유효기간이 지나도 상사채권 소멸시효(5년, 상법 제64조) 안이면 구매액의 90% 상환, 영업양도 때도 상환의무.
   - 「중요한 표시·광고사항 고시」 Ⅳ.2: 현금 액수를 적은 상품권은 권면에 잔액 환불 기준·유효기간 경과 시 보상기준·사용제한을 표시.
   - 「인지세법」 제3조 제1항 제8호·시행령 제5조의2: 금액이나 수량을 적어 발행한 증표는 인지세 과세문서 소지.
3. 질문
   가. 위 회수권·선불권도 소비자분쟁해결기준의 '상품권'(④-1)으로 보아 같은 환급 기준을 적용합니까? 할인가로 판 회수권(10회권을 9회 값)의 미사용분 환급액은 어떻게 계산합니까?
   나. 권면에 "유효기간 1년, 기간 지나면 소멸", "환불 불가"라고 적으면 약관규제법상 무효입니까? 유효기간을 둔다면 어떤 문구가 안전합니까?
   다. 가게를 넘길 때(양도) 새 주인이 옛 회수권을 이어서 받아야 합니까?
   라. 「중요한 표시·광고사항 고시」의 표시 의무는 수량형 회수권(커피 10잔 등)에도 적용됩니까?
