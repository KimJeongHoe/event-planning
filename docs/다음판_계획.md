# 다음 판 계획 (2026-11-04, 미리보기 판 5 기준)

## A. 응용 예제 범위안 (사용자 OK를 받은 뒤 만든다)

### 무엇을 만드나
실제 사례를 소재로, 입력한 가게 상황에 맞게 바꾼 「응용 예시」. 화면에서는 실제 사례와 다른 색의 「응용 예시」 표시와 근거 실제 사례 번호를 붙인다.
- 숫자(가격·할인율·효과)는 쓰지 않는다. 혜택은 「○○원 할인」「사이드 1접시」처럼 비워 두거나 가게 메뉴 이름으로만 쓰고, 원가·본전은 화면의 계산식으로만 낸다. 효과는 적지 않는다.
- 판정은 근거 실제 사례와 연결 FAQ 중 **가장 엄격한 것**을 따른다. 안전운영조건은 근거 사례 것을 그대로 붙인다. 공지문은 같은 「피해야 할 표현」 검사를 받는다.
- 시점이 맞지 않는 소재(예: 2002 월드컵 승리 다음 날)는 「경기·기념일이 있을 때」 같은 조건으로 바꾸고, 날짜는 캘린더 파일에 있는 것만 쓴다.

### 조합 범위 (1차)
| 축 | 1차에 나누는 값 | 나누지 않고 꼬리표·필터로 처리 |
|---|---|---|
| 세부 업종 | 고깃집, 카페, 미용실, 치킨·호프(술 판매 가게) — 4개 | — |
| 단계 | 오픈 전·가오픈 / 그랜드오픈 / 정착기(1~3개월) / 상시·비수기 / 위기회복·리뉴얼 — 5묶음 | — |
| 목표 | 나누지 않음 | 예제마다 목표 꼬리표(신규·재방문·객단가·비피크·리뷰 등)를 달아 같은 상황 안에서 순서만 바꿈 |
| 술 판매 | 나누지 않음 | 고깃집·치킨·호프 예제에 「술 판매 가게라면」 줄을 붙임(거래: 값을 받고 판매 / 알리기: 술 할인·증정 표시 금지) |
| 예산 | 나누지 않음 | 예제마다 1회 원가 수준(거의 없음·낮음·중간) 꼬리표 → 지금처럼 예산으로 뒤로 뺌 |
| 손님 종류 | 일반 손님만 | 입점·가맹·임차(사례 5건), 거래처(0건), 구직자(6건)는 근거가 적어 1차에 만들지 않음 |

→ **1차: 4 업종 × 5 단계 = 20 상황, 상황마다 3개 = 응용 예시 60개.**
2차 후보: 한식·백반, 베이커리, 학원, 동네 소매 4 업종 × 5 단계 = 20 상황 × 3 = 60개.

### 만들지 않은 조합
가장 가까운 예제를 보여 주고 「○○ 상황 예제가 없어 △△ 기준 예제를 보여 줍니다」라고 적는다. 가깝기는 ① 같은 단계 ② 같은 업종 묶음(요식업 안에서 고깃집↔한식↔치킨, 카페↔베이커리, 미용실↔네일 등) ③ 술 판매 여부 순으로 본다.

### 만드는 방법과 검사
제가(이 세션) 근거 사례를 읽고 예제 자료(JSON)를 써서 화면에 넣는다. 화면 안 AI 생성은 쓰지 않는다. 예제마다 ① 숫자 검사(가격·%·효과 숫자가 있으면 경고) ② 피해야 할 표현 검사 ③ 판정이 근거 사례보다 느슨하지 않은지 검사를 자동으로 돌린다.

## B. 쿠폰 만들기 (다음 판 후보, 이번에는 구현하지 않음)

### 흐름
고른 행사안 → 쿠폰 초안(혜택·조건 채움) → 검사(술·표시·유효기간) → 내보내기(디자인 메이커용 인쇄 문안, QR 오더용 발급 목록) → 사용 확인(일련번호로 사용 처리).

### 속성(최소)
| 속성 | 값(안) |
|---|---|
| 쿠폰 종류 | 할인(금액) / 할인(%) / 증정 / 업그레이드 / 적립 도장 / 재방문 |
| 혜택 | 고른 안의 혜택 문장(숫자는 사장님이 넣음) |
| 사용 조건 | 최소 주문, 메뉴, 요일·시간, 인원 |
| 유효기간 | 시작일·끝일(날짜로 적음, 「발급 후 ○일」은 날짜로 바꿔 표시) |
| 사용 제한 | 1인·1테이블 1장, 다른 할인과 중복 여부, 현금 교환 불가 여부 |
| 일련번호 | 가게 약자-날짜-순번(예: ABC-20261104-0001), 개인정보 없음 |
| 발급 수 | 숫자(사장님 입력) |
| 사용 확인 방법 | 종이: 도장·절취 / 문자: 번호 확인 / QR: QR 오더 도구에서 사용 처리 |
| 받는 형태 | 종이 인쇄 / 문자 / QR |
| 주의 문구 | 유효기간·사용 조건·중복 여부를 쿠폰 앞면에 표시 |

### 검사(빼지 않고 경고와 근거를 보임)
- 술 할인·무료 쿠폰: 국세청 「주류 거래질서 확립에 관한 명령위임 고시」(주류 경품·교환권 — 사례 DB 원문 확인분 F004·F051)와 국민건강증진법 제8조의2 제2항 제1호(광고에 할인·증정 표시, F075)로 경고.
- 유효기간·사용 조건 표시 기준: 구현하는 판에서 원문으로 확인한다. 확인할 것은 소비자분쟁해결기준(쿠폰·상품권 항목), 공정위 신유형 상품권 표준약관, 표시광고법이다. 확인 전에는 「확인 필요」로 둔다.
- 개인정보: 받지 않음(이름·전화번호 칸 없음). 문자 쿠폰은 수신 동의한 손님에게만(F015).

### 다른 도구와 주고받는 파일(안)
- 디자인 메이커용 `쿠폰_인쇄.csv`: 쿠폰 종류, 앞면 문구, 뒷면 주의 문구, 유효기간, 크기(명함·A6), 일련번호 시작·끝.
- QR 오더용 `쿠폰_발급목록.csv`: 일련번호, 쿠폰 종류, 혜택, 조건, 유효기간 시작·끝, 상태(발급/사용/만료), 사용 일시(사용 처리 때 채움). 개인정보 칸 없음.
