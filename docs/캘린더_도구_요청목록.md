# 캘린더 도구에 요청할 목록 (행사 기획에 필요한 날짜)

이 도구(사례 DB·행사안 생성)는 날짜를 만들지 않는다. 날짜의 원본은 사용자의 캘린더 도구 DB이고, 이 도구는 받은 목록 파일(`생성/캘린더.csv`)만 쓴다. 파일이 없거나 기준일이 오래되면 날짜를 지어내지 않고 **「달력 자료 없음」**으로 적는다. 화면·행사안에는 항상 **「캘린더 ○○ 기준」**(○○ = 파일의 기준일)을 붙인다.
캘린더 DB에 이미 있는 항목은 사용자가 확인해 알려 주기로 했다. 아래 표의 「있음 / 없음」 칸은 비워 두었다.

## 1. 항목마다 필요한 속성 (CSV 칸)
| 칸 | 뜻 | 값 예시 |
|---|---|---|
| 날짜 | 시작일(기간이면 종료일 칸 따로) | 2027-02-06 ~ 2027-02-09 |
| 이름 | 항목 이름 | 설날 연휴 |
| 종류 | 공휴일 / 대체공휴일 / 명절 연휴 / 기념일 / 급여일 관행 / 시험 / 방학·학사 / 계절·절기 / 스포츠 / 지역 행사 / 세무·행정 | 명절 연휴 |
| 지역 범위 | 전국 / 시도 / 시군구 | 전국, 대구광역시 |
| 출처 | 원본의 이름·주소(공식 고시·기관 공지 등) | 인사혁신처 월력요항 |
| 기준일 | 이 항목을 마지막으로 확인한 날짜 | 2026-11-03 |
| 확정 여부 | 확정 / 예정 / 추정 (예정·추정이면 행사안에 확정처럼 쓰지 못함) | 확정 |
| 비고 | 쉬는 날 여부, 영업에 영향 등 | 가게 휴무 많음 |

이 도구는 다음 규칙으로만 읽는다: ① 기준일이 90일 넘게 지났으면 「달력 자료 없음(기준일이 오래됨)」 ② 확정 여부가 확정이 아니면 행사안에 「예정」으로 표시 ③ 출처 칸이 비면 쓰지 않음.

## 3. 받은 뒤 이 도구가 하는 일
- 참고 묶음(`scripts/pick_cases.py`)이 `생성/캘린더.csv`를 읽어 행사 기간 안의 항목만 「캘린더 ○○ 기준」과 함께 붙인다.
- 파일이 없으면 참고 묶음에 「달력 자료 없음」이 적히고, 생성문 v4는 날짜를 만들지 않는다. 행사안의 「한 달 달력」도 같은 말로 둔다.
- 행사안 검사(`check_plan.py`)는 아직 날짜를 따로 검사하지 않는다(해야 할 일: 달력 파일에 없는 날짜가 행사안에 나오면 경고).
