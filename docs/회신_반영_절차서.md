# 질의 회신 반영 절차서 (다른 도구 창도 같은 순서로)

질의(국민신문고·부처·세무서·선관위 등) 회신이나 새 공식 자료가 오면 아래 순서로 반영한다. 원칙: 회신 원문(PDF·화면)을 law_src/참고/에 저장한 것만 근거로 쓴다. 요약·기사로만 받은 것은 근거로 쓰지 않는다.

## 1. 받기
1. 회신 원문을 `law_src/참고/<기관>_<쟁점>_<회신일>.txt`(PDF면 글자로 바꾸고 첫 줄에 원문 위치·접수번호)로 저장. 개인 정보(이름·연락처)는 지운다.
2. docs/공식판단_대기목록.md에서 해당 FAQ·사례를 찾는다(질의 문안 파일의 '회신을 받으면 고칠 곳' 목록도 본다).

## 2. 판정 바꾸기
| 회신 내용 | FAQ | 사례 법 칸 | 법확인필요사유 | 근거수준(자동) |
|---|---|---|---|---|
| 쟁점에 직접 답함(허용·금지 결론) | 진행여부·이유·조건을 회신대로 고치고 비고의 '[확인 필요 사유: …]' 삭제 | 끝에 `[공식 판단: <기관> 회신 <날짜> — 요지 → 결론]` 덧붙임 | "" (다른 쟁점이 남으면 그 사유) | '부처 공식 자료 확인'(보도·Q&A·회신) 또는 '공식 해석·판례 확인'(법제처·판례) |
| 일부만 답하거나 일반론 | 이유에 회신 요지 추가, 진행여부는 유지 | `[참고 판단: …]` | 유지 | 유지(보조로 '부처 자료 있음') |
| 답하지 않음·관할 아님 | 비고에 "회신: 관할 아님(기관·날짜)" | 손대지 않음 | 유지 | 유지 |

- 모든 수정은 `python3 -I scripts/edit_raw.py`(사례)·`python3 scripts/apply_faq.py`(FAQ)로 하고 이유 칸에 "회신 반영(<기관> <날짜>)"을 적는다(수정기록에 남음).
- 회신이 지금 판정보다 엄격하면 공지문 문구 은행(spec/공지문_문구은행.csv)의 권장 문구도 같이 고친다.

## 3. 다시 만들기·검사
1. `bash scripts/pack.sh <출력폴더>` — merge → 유사묶음 → 도구 CSV → 대기 목록 → 자동 검사가 차례로 돈다.
2. 통계.md 맨 앞 '자동 경고'가 0인지 본다. 대기 목록에서 해당 FAQ가 빠졌는지(또는 순위가 내려갔는지) 확인.
3. 질의 문안 파일 맨 위에 "회신 반영 완료(<날짜>)"를 적는다.

## 4. 알리기
- 회차 보고 '된 것' 표에 "회신 반영: <기관> <쟁점> → FAQ F0xx 진행여부 <전>→<후>, 사례 N건"을 적고, QR 오더·디자인 메이커 등 받는 도구에 바뀐 CSV를 다시 보낸다.
