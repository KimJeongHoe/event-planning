# 다른 도구와 잇는 파일 — 칸 설명서 (판 8, 2026-11-04)

「사장님 행사안 고르기」 화면은 다른 도구가 만든 파일 3개를 받으면 그대로 연결합니다. 이 문서는 **어떤 모양의 파일을 보내면 되는지** 적은 것입니다. 받기 전까지 화면에는 「연결 대기」가 보이고, 사장님이나 다른 도구 담당자는 화면 4단계 「연결 파일(다른 도구)」에서 같은 모양의 파일을 불러와 미리 시험해 볼 수 있습니다(시험 파일은 그 브라우저에만 남음).

| 파일 | 보내는 도구 | 파일 이름(넣을 곳) | 화면에서 쓰는 곳 |
|---|---|---|---|
| 문구 기준 | 구절 공방 | `spec/연동/문구기준.json` | 3단계 「홍보 글」 표현 검사에 규칙을 더함 |
| 배달 요금표 | 배달 실수령 | `spec/연동/배달요금표.json` | 4단계 「배달앱 할인 실수령」에서 요금제를 골라 칸을 채움 |
| 개업 순서표 | 개업 D-데이 순서표 | `spec/연동/개업순서표.json` | 4단계 「개업 행사 한 묶음」 순서표에 할 일을 더함 |

받은 파일을 위 자리에 두고 `python3 scripts/build_preview.py`를 돌리면 화면에 들어갑니다. 칸이 틀린 파일은 화면이 쓰지 않고 「연결 대기」로 남깁니다(무엇이 틀렸는지는 「연결 파일」 도구에서 불러오면 나옴).

## 공통 규칙
- 글자: UTF-8 JSON 한 개. 맨 바깥은 `{ }` 묶음.
- 필수 칸: `종류`(아래 세 가지 중 하나, 글자 그대로), `기준일`(`YYYY-MM-DD`, 그 파일 내용이 맞는 날), `출처`(도구 이름·만든 사람 역할. 개인 이름·연락처 금지).
- 선택 칸: `예시`(true면 화면에 「예시 파일(실제 값 아님)」 표시), `판`(파일 판 번호).
- 손님 개인정보·전화번호·주민번호·이메일은 넣지 않습니다. 그런 모양이 보이면 화면이 파일 전체를 받지 않습니다.
- 숫자는 따옴표 없는 숫자로(`7.8`, 아니고 `"7.8"`가 아님). 퍼센트 칸은 % 기호 없이 숫자만.

## 1. 문구 기준 (`종류`: `문구기준`)
| 칸 | 필수 | 값 | 설명 |
|---|---|---|---|
| 규칙 | 필수 | 목록(최대 500개) | 검사 규칙 |
| 규칙[].번호 | 필수 | 글자 | 규칙 번호(화면에 「문구 기준 G001」처럼 표시) |
| 규칙[].찾기 | 필수 | 글자 | 찾을 낱말 또는 정규식 |
| 규칙[].방식 | 필수 | `낱말` 또는 `정규식` | 낱말은 그대로 포함 여부, 정규식은 자바스크립트 정규식 문법 |
| 규칙[].채널 | 필수 | 목록 | `전체`·`매장`·`인스타그램`·`플레이스`·`카카오톡`·`문자`·`배달앱`·`당근`·`현수막` 중에서 |
| 규칙[].수준 | 필수 | `금지` 또는 `주의` | 금지는 ⚠ 표시 |
| 규칙[].이유 | 필수 | 글자 | 사장님이 읽을 한 줄 |
| 규칙[].근거 | 선택 | 글자 | 법령 조문·지침 이름(예: 「표시광고법 제3조」). 원문 확인한 것만 |
| 규칙[].바꿔쓰기 | 선택 | 글자 | 대신 쓸 표현 |

화면의 기존 검사(술 할인 표시, 문자 광고 표시 등)는 그대로 두고 이 규칙을 **더해서** 검사합니다.

## 2. 배달 요금표 (`종류`: `배달요금표`)
| 칸 | 필수 | 값 | 설명 |
|---|---|---|---|
| 요금 | 필수 | 목록(최대 200개) | 앱·요금제·구간별 한 줄 |
| 요금[].앱 | 필수 | 글자 | 배달앱 이름 |
| 요금[].요금제 | 필수 | 글자 | 요금제 이름 |
| 요금[].구간 | 선택 | 글자 | 매출 구간 등 적용 조건 |
| 요금[].중개수수료율 | 필수 | 숫자 0~50 | % (예: 9.8) |
| 요금[].결제수수료율 | 필수 | 숫자 0~10 | % |
| 요금[].배달비_사장님부담 | 필수 | 숫자(원) 또는 `null` | 모르면 null(화면 칸을 비워 둠) |
| 요금[].부가세 | 필수 | `별도` 또는 `포함` | 별도면 화면이 수수료·배달비에 10%를 더함 |
| 요금[].수수료기준 | 필수 | `할인 전 금액` 또는 `할인 뒤 금액` | 수수료를 매기는 금액 |
| 요금[].확인일 | 필수 | `YYYY-MM-DD` | 앱 공지·계약서에서 확인한 날 |
| 요금[].출처주소 | 선택 | 주소 | 공식 공지 주소 |
| 요금[].메모 | 선택 | 글자 | 예: 「가게 배달만」 |

화면은 요금표 값을 칸에 채우기만 하고, 사장님이 계약과 다르면 고쳐 넣을 수 있습니다. 이 도구는 요율을 스스로 넣지 않습니다(판 7 원칙 유지).

## 3. 개업 순서표 (`종류`: `개업순서표`)
| 칸 | 필수 | 값 | 설명 |
|---|---|---|---|
| 업종 | 선택 | 목록 | 이 순서표가 맞는 업종(예: `요식업`, `미용·뷰티`). 없으면 모든 업종 |
| 할일 | 필수 | 목록(최대 300개) | 할 일 한 줄씩 |
| 할일[].D | 필수 | 정수 −90~90 | 개업일 = 0, 개업 30일 전 = −30 |
| 할일[].할일 | 필수 | 글자 | 할 일 |
| 할일[].분류 | 선택 | `인허가`·`준비`·`홍보`·`행사`·`사후` | |
| 할일[].근거 | 선택 | 글자 | 법령 조문 등(원문 확인한 것만) |
| 할일[].도구 | 선택 | `coupon`·`review`·`infl`·`regular`·`draw`·`deliv`·`open`·`result`·`near` | 이 화면의 어느 도구로 이어 줄지(도구 키) |

날짜는 이 화면이 개업일에서 계산합니다. 공휴일·명절 겹침은 계속 캘린더 파일(생성/캘린더.csv)에서만 가져옵니다.

## 시험용 예시 파일
`docs/연동예시/문구기준_예시.json`, `배달요금표_예시.json`, `개업순서표_예시.json` — 모두 `"예시": true`이고 **실제 값이 아닙니다**(요율 칸은 0). 모양을 맞춰 볼 때만 쓰세요. `spec/연동/`에 넣지 마세요.

# 보내는 파일 (판 11) — 이 도구가 다른 도구에 넘기는 파일

도구끼리 직접 잇지 않고 파일로만 넘깁니다. 모든 파일은 UTF-8이고 맨 바깥에 `종류`·`기준일`(한국 기준)·`출처`가 있습니다. 손님 이름·연락처는 넣지 않습니다. 사례 글은 업체 실명을 뺀 글입니다.

| 파일 | 받는 도구 | 만드는 곳 | 칸 |
|---|---|---|---|
| `쿠폰발급목록_날짜.json` | 디자인 메이커·QR 오더·포스 | 4단계 「행사용 쿠폰」 → 묶음의 「다른 도구용 파일」 | 종류 `쿠폰발급목록`, 판, 묶음{종류·혜택·시작·끝·조건}, 번호[{번호, 확인글자(번호 끝 두 글자), QR글(QR 안 글 그대로), 상태(발급·사용·만료), 사용일시}]. 확인 글자를 만드는 비밀값은 넘기지 않음 |
| `문자발송용_날짜.csv` | 문자 발송 도구(특정 사업자에 묶지 않음) | 3단계 「홍보 글」 → 「문자 발송용 파일 내려받기」 | 본문, 바이트, 광고 표시(있음/없음), 무료 수신거부(있음/없음), 보낼 수 없는 시간, 받는 사람(빈칸 — 발송 도구에서 수신 동의한 손님만) |
| `공동구매_발주_날짜.json` | 발주 도구 | 4단계 「공동구매 행사」 → 「발주용 파일」 | 종류 `공동구매발주`, 품목, 묶음수량, 묶음수, 낱개합계, 주문마감, 수령일 |
| `동네코스_날짜.json` | 지도 도구 | 4단계 「동네 코스·문화공간」 → 「지도용 파일」 | 종류 `동네코스`, 이름, 행사, 장소[{순서, 이름, 소개, 주소(사장님 입력), 다음까지_걸어서_분}] |
| `행사계획_날짜.csv` | 캘린더·일정 도구 | 4단계 「올해 행사 달력」 → 「계획 CSV」 | 날짜, 종류(행사·이슈 시점·매주), 이름, 메모, 달력 날 |
| `merged/다른도구용/배달실수령용_행사근거.json` | 배달 실수령 도구 | `scripts/export_off9.py`(묶음 만들 때 자동) | 계산식, 입력칸, 법근거, FAQ |

| `merged/다른도구용/QR오더용_사례.csv`, `디자인메이커_공지물용_사례.csv` | QR 오더·디자인 메이커 | `scripts/export_tools.py` | 주제별 사례(실명·출처 주소 뺌) |
