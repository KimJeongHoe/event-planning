# 배지 표시 규칙 (디자인 메이커·QR 오더 공통, 2026-11-03)

사례·FAQ 화면과 도구용 CSV에서 '얼마나 확실한가'를 같은 방식으로 보여 주기 위한 규칙. 칸: `진행여부`(FAQ·사례별 질문과 답), `근거수준`(본 배지), `관련FAQ근거`(보조 배지), `불확실한 부분(공식 해석 없음)`(QR 오더 CSV).

## 1. 보여 주는 순서
1. 진행여부 배지 → 2. 근거수준 배지(본) → 3. 관련FAQ근거(보조, 작게) → 4. 안전운영조건(본문 첫 줄) → 5. 불확실한 부분(펼침 안내)

## 2. 진행여부 배지
| 값 | 색 | 아이콘 | 문구 |
|---|---|---|---|
| 가능 | 초록 | ✓ | 해도 됩니다 |
| 조건부 가능 | 파랑 | ⓘ | 조건을 지키면 됩니다 |
| 확인 필요 | 주황 | ? | 관할 기관 확인 후 |
| 불가 | 빨강 | ✕ | 하지 마세요 |
※ 색만으로 구분하지 않고 아이콘·문구를 함께 쓴다(색각 이상 사용자 배려).

## 3. 근거수준 배지(본)
| 값 | 색 | 짧은 표시 | 뜻 |
|---|---|---|---|
| 법령 원문 확인 | 진한 회색 | 법령 확인 | 법령·고시·별표 원문으로 확인 |
| 공식 해석·판례 확인 | 남색 | 판례·해석 | 대법원·법제처 등 공식 판단 원문 |
| 부처 공식 자료 확인 | 청록 | 부처 자료 | 부처 보도자료·Q&A 원문 |
| 조문 해석만(공식 해석 원문 없음) | 주황 테두리 | 해석 없음 | 조문만으로 판단, 공식 판단 없음(+참고 판례·부처 자료 있음 표시) |
| 원문 없음(대체 근거) | 주황 | 원문 없음 | 원문을 못 받아 다른 근거 사용 |
| 사실 확인 필요 | 노랑 | 사실 확인 | 가게 사정(규모·계약 등)에 따라 달라짐 |
| 조례 예시만 확인 | 노랑 | 조례 다름 | 지자체마다 다름 |
| 해외 법(국내 기준만 확인) | 회색 | 해외 | 국내에서 따라 할 때 기준만 확인 |
| FAQ 근거 따름(F0xx) | 연회색 | FAQ 참고 | 근거는 해당 FAQ |
| 법 쟁점 적음 / 법적 의무 없음(운영 권고) | 연회색 | 법 쟁점 적음 | 운영 권고 수준 |

## 4. 관련FAQ근거(보조 배지)
- 값이 있으면 근거수준 배지 오른쪽에 작은 회색 글씨로 "관련 FAQ 해석 없음"만 보여 주고, 누르면 FAQ 번호 목록을 펼친다.
- 본 배지보다 눈에 띄게 하지 않는다(사례 자체 근거가 확실해도 관련 FAQ 쟁점이 남았다는 정보일 뿐).

## 5. 불확실한 부분
- QR 오더 CSV의 `불확실한 부분(공식 해석 없음)` 칸, 테이블오더 계약 점검표의 `공식 해석 없는 부분` 칸은 ⚠ 아이콘과 "확실하지 않아요"를 붙여 본문 아래 접힌 상자로 보여 준다.
- 진행여부가 '조건부 가능'이어도 이 칸이 있으면 안전운영조건을 반드시 함께 보여 준다(생성문 규칙과 같음).

## 6. 공통
- 배지 문구는 쉬운 말, 한 줄 15자 이내. 법령 이름·조문은 배지가 아니라 펼친 본문에.
- 날짜가 있는 의무(키오스크 2026.1.28 등)는 시행일 점검 목록과 같은 날짜를 쓴다.

## 7. CSV 표시용 칸 (회차15, scripts/export_tools.py가 이 규칙대로 채움)
- 사례 도구 CSV(QR 오더·디자인 메이커): `진행여부(질문과 답)`, `진행여부_색`, `진행여부_표시`(아이콘+문구), `근거수준_짧은표시`, `근거수준_색`, `관련FAQ_보조배지`
- FAQ: merged/다른도구용/FAQ_표시용.csv — FAQ.csv에 `진행여부_색`, `진행여부_표시`, `근거수준_짧은표시`, `근거수준_색`을 더한 것
