## 4. 업종 전용 질문(원본: spec/업종질문_판10.json)

- (편의점) 담배를 파나요? → 「예」면: 담배는 할인·덤·사은품 행사 대상이 아닙니다. 공고된 가격대로 팔고, 담배 광고물은 행사 홍보에 쓰지 마세요.
- (편의점|노래|숙박|PC방|보드게임) 청소년(만 19세 미만) 손님도 오나요? → 「예」면: 술·담배가 들어간 행사는 나이 확인이 필수이고, 청소년 출입·이용 시간 제한(PC방·노래연습장 등)을 행사 안내문에도 적으세요.
- (정육) 가게에서 고기를 잘라 양념·가공해 파나요? → 「예」면: 가공해 파는 고기도 100g당 가격·등급·이력번호 표시를 지키고, 택배로 보내는 행사는 낱개 표시가 필요합니다.
- (헬스|체육|필라테스|요가) 이용권을 몇 달 이상 미리 팔 계획인가요? → 「예」면: 장기 이용권은 중도 해지 때 법정 반환 기준대로 돌려줘야 하고, 휴업·폐업 전 미리 알릴 의무가 있습니다. 평생권·초장기권 특가는 피하세요.
- (화장품) 견본품(샘플)을 나눠 줄 계획인가요? → 「예」면: 견본품은 팔 수 없고(덜어 팔기 포함), 의약품처럼 읽히는 효능 표현을 쓰지 마세요.
- (미용|네일|피부) 피부관리 기기(레이저·고주파 등)를 쓰나요? → 「예」면: 의료기기를 쓰는 체험·이벤트는 하지 마세요. 시술 요금은 최종지급요금표대로 받고 내역서를 주세요.
- (숙박) 지금이 성수기(연휴·휴가철)인가요? → 「예」면: 성수기에도 게시한 요금표보다 비싸게 받으면 안 됩니다. 특가를 걸 때는 요금표·온라인 요금도 같이 고치세요.
- (정비|세차) 무료 점검이 실제 정비로 이어질 수 있나요? → 「예」면: 점검 뒤 정비를 하면 견적서를 먼저 주고 동의를 받으세요. 진단 요금은 미리 알린 경우에만 받습니다.
- (학원|교습|태권) 등록한 교습비와 다른 행사 가격을 쓸 건가요? → 「예」면: 교습비는 등록·게시한 금액과 달리 받을 수 없습니다. 할인을 하려면 게시표부터 고치고, 광고에 교습비와 등록번호를 함께 적으세요.
- (병의원|치과|한의원|약국|동물병원) 진료비·약값을 깎거나 선물을 주는 행사를 생각하나요? → 「예」면: 본인부담금 할인·면제, 사은품·경품, 소개 보상은 환자 유인으로 금지됩니다. 행사 대신 진료 안내·건강 강좌 같은 안내형으로 바꾸세요.
