# 국가법령정보센터 별표 PDF 직접 받기 — 다른 도구 창용 짧은 안내 (2026-11-03)

## 1. 순서
1. 법령 본문 페이지 주소를 정한다 (첨부 링크가 이 페이지 HTML 안에 있다).
   - 법령: `https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=<번호>`
   - 행정규칙(고시·훈령): `https://www.law.go.kr/LSW/admRulInfoR.do?admRulSeq=<번호>`
   - 자치법규(조례): `https://www.law.go.kr/LSW/ordinInfoR.do?ordinSeq=<번호>`
   - 일반 화면 주소(`lsInfoP.do`, `ordinInfoP.do`)는 껍데기만 오므로 끝의 P를 R로 바꾼다.
2. 본문 HTML에서 `[별표 N] 제목` 다음에 나오는 첨부 링크를 찾는다. 그림 alt 값에 "PDF"가 들어 있는 링크를 고른다 (HWP 링크도 같이 있다).
3. 그 주소로 PDF를 받는다. **referer(-e)에 1번의 본문 주소를 꼭 넣는다.**
4. 받은 파일이 `%PDF`로 시작하는지 확인하고 `pdftotext -layout`으로 텍스트로 바꾼다.

## 2. 받는 주소 형식
| 종류 | 형식 |
|---|---|
| 법령 별표 | `https://www.law.go.kr/LSW/flDownload.do?gubun=&flSeq=<숫자>&bylClsCd=<숫자>` |
| 행정규칙 별표 | `https://www.law.go.kr/LSW/flDownload.do?flSeq=<숫자>&flNm=<파일이름>&bylClsCd=200201` |
| 자치법규(조례) 별표 | `https://www.law.go.kr/LSW/flDownload.do?gubun=ELIS&flSeq=<숫자>&flNm=<별표 이름>` — **HWP 파일**로 옴(PDF 아님) |

HTML 안에서는 `&`가 `&amp;`로 적혀 있으므로 풀어서 쓴다.

예시:
```bash
curl -s -L -A "Mozilla/5.0" -e "<본문주소>" -o a.pdf "https://www.law.go.kr/LSW/flDownload.do?gubun=&flSeq=<n>&bylClsCd=<cd>"
head -c 5 a.pdf    # %PDF 이어야 함
pdftotext -layout a.pdf a.txt
```
이 DB에서는 `python3 scripts/bylfetch.py list "<법령이름 일부>"`로 목록을 보고, `python3 scripts/bylfetch.py get "<법령이름 일부>" 14 17`로 받는다. 결과는 `law_src/별표/<법령>__별표N.txt`에 저장되고, 첫 줄에 원문 PDF 주소가 적힌다.

## 3. 막히는 경우
| 증상 | 원인 | 대처 |
|---|---|---|
| PDF 대신 HTML(오류·첫 화면)이 옴 | referer가 없거나 law.go.kr 주소가 아님 | `-e`에 본문 주소를 넣고 다시 받는다 |
| 본문에 별표 링크가 없음 | `...InfoP.do` 주소를 썼음 | `...InfoR.do`로 바꾼다 |
| 행정규칙에서 링크를 못 찾음 | `flNm=` 이 붙은 형식 | 2번 표의 행정규칙 형식으로 찾는다 |
| 받은 파일이 GIF 등 그림 | 별표가 아니라 '첨부'만 있는 고시 | 별표 없음으로 기록한다. 원문을 사람이 따로 받아야 한다 |
| pdftotext 결과가 비어 있음 | 표가 그림으로 된 PDF | 페이지를 그림으로 열어 직접 읽고 옮겨 적는다. 옮긴 파일에 "그림 PDF에서 옮겨 적음"이라고 표시한다 |
| 조례 검색 결과가 0건이거나 다른 조례가 나옴 | 조례 이름이 정확하지 않음 | 정식 이름 전체를 쓴다 (예: "서울특별시 옥외광고물 등의 관리와 옥외광고산업 진흥에 관한 조례") |
| 조례 별표가 HWP라 pdftotext가 안 됨 | 조례 첨부는 HWP만 줌 | pyhwp의 `hwp5html`로 바꿔 표를 살린다(`hwp5txt`는 표 안 글자를 '<표>'로 버림). 표 줄 맞춤이 어긋날 수 있으니 금액은 처음·끝 값 위주로 쓰고 중간 구간은 원문과 맞춰 본다 |
| 법률 본문 안의 표(예: 인지세법 제3조 세율표)가 없음 | 별표가 아니라 조문 속 표라서 HTML에서 빠짐 | 사용자에게 PDF 원문을 받아 옮겨 적는다 |

## 4. 주의할 점
- **우회 금지.** 위 방법은 사이트가 제공하는 내려받기 링크를 정상 경로로 받는 것이다. 다른 방법으로 막히면 프록시·캐시 사이트·보관 사이트(archive 등)로 돌아가지 말고 막힌 목록(reports/막힌사이트.tsv)에 적는다.
- **시행일을 확인한다.** 본문 페이지가 현행판인지, 개정 예정판인지 본다. 저장 파일 3번째 줄의 제목·개정일을 보고, 사례 날짜와 맞는 판인지 따진다.
- **줄이 밀릴 수 있다.** pdftotext -layout은 표 칸이 밀리기 쉽다. 금액·기간·비율 같은 수치는 PDF 원래 화면과 한 번 더 맞춰 본다.
- **어느 별표인지 함께 적는다.** 법 근거 칸에는 "법령명 별표 N 몇 호 몇 목"까지 적고, 원문 PDF 주소를 남긴다.
- **조금씩 받는다.** 한 번에 수십 개를 연달아 받지 않는다. 받은 것은 저장해 두고 다시 받지 않는다.
- **판정은 따로 한다.** 별표를 받았다고 '가능/불가'가 정해지지는 않는다. 업종·상황에 맞는지 판단이 필요하면 법 칸에 "확인 필요(적용 해석)"로 남긴다.

## 5. 이름으로 본문 주소를 못 찾을 때 (행정규칙·조례)
- `law.go.kr/행정규칙/<이름>` 주소가 '목록 없음'이면(예: 고시 이름 앞에 부처명이 붙은 "(산업통상자원부) 가격표시제 실시요령") 검색 목록을 직접 불러 번호를 찾는다:
  `curl -s -A "Mozilla/5.0" -H "X-Requested-With: XMLHttpRequest" --data-urlencode "q=<낱말>" --data "section=admRulNm&outmax=50&pg=1&p6=1,2,3&admType=N" https://www.law.go.kr/LSW/admRulScListR.do`
  결과의 `showAdmRulCts('<번호>', …)`가 admRulSeq. 같은 이름의 옛 판·다른 부처 고시가 섞여 나오니 제목 뒤 [시행 날짜·고시 번호]로 고른다.
- 그다음 `admRulInfoR.do?admRulSeq=<번호>` 본문에서 `flDownload.do?flSeq=…&flNm=…&bylClsCd=2002xx` 첨부를 받는다(HWPX와 PDF가 짝으로 있음, referer 필요).
- 법령해석례·판례도 같은 방식: `expcScListR.do`·`precScListR.do`에 `q=<낱말>&section=bdyText` → `expcInfoR.do?expcSeq=`·`precInfoP.do?precSeq=`로 원문. 이 DB에서는 `scripts/lawsearch.py`.
