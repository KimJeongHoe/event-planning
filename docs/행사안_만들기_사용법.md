# 행사안 만들기 사용법 (2026-11-03, 생성문 v4)

## 순서
1. **입력 채우기**: 생성/입력_예시.json을 복사해 가게 정보를 적는다(업종·세부업종·상권·단계·시점·목표·주 손님층·주류 판매·테이블오더·소상공인 여부·예산·인력·주력 메뉴 가격과 원가·남는 재료·SNS·단골 연락처 동의). 모르는 칸은 비워 둔다.
2. **원가·본전 계산**: 메뉴 가격·원가와 행사안 후보를 `생성/원가입력_<가게>.json`에 적고 `python3 scripts/calc_cost.py <원가입력.json>` → 생성/계산결과_<가게>.md. 원가율·1회 원가·본전 필요 추가 손님 수·할인율은 이 파일의 값만 행사안에 쓴다. 입력이 없으면 「계산 불가(입력 없음: …)」로 나오고, 그 칸은 사장님께 물어 다시 계산한다(지어내지 않음). 예시: 생성/원가입력_고깃집.json
3. **참고 묶음 만들기**: `python3 scripts/pick_cases.py <입력.json> [사례 수, 기본 20]` → 생성/참고묶음_<업종>_<단계>.md
   - 참고제외 제외, 업종·단계·시점·상권·목표·대상 점수, 원문 확인·한국·실제 우대, 유사묶음은 대표 우선·묶음당 2건, 오픈 단계에서는 양도·폐업정리·위기회복 사례를 뒤로, 성격별로 고르게.
   - 사례마다 진행여부·근거수준·안전운영조건(법확인필요사유가 있으면), 걸린 FAQ의 조건·대안, 공지문 문구 은행의 권장·피할 표현이 들어간다. 맨 위 '사장님께 물을 것'은 입력 빈칸 목록.
   - **달력**: 날짜는 이 도구에서 만들지 않는다. 사용자의 캘린더 도구가 준 목록을 `생성/캘린더.csv`로 두면(칸: 날짜·이름·종류·지역 범위·출처·기준일·확정 여부, 자세히는 docs/캘린더_도구_요청목록.md) 앞으로 60일 안의 항목이 「캘린더 ○○ 기준」과 함께 묶음에 들어간다. 파일이 없거나 기준일이 90일 넘게 지났거나 출처가 비면 「달력 자료 없음」.
4. **생성**: 생성 모델에 `spec/생성문_v4.txt` + 입력 + 참고 묶음 + 계산 결과를 함께 준다. 먼저 '간단판'(핵심 칸만)을 받고, 사장님이 고른 안만 '자세한 판'(21개 속성)으로 받는다.
5. **검사**: `python3 scripts/check_plan.py <행사안> <참고 묶음> <계산 결과>`
   - 종료 0 통과 / 1 경고 / 2 검사 대상 없음(본문이 너무 짧음). 2와 「참고 묶음·계산 결과 없이 돌림」은 통과로 치지 않는다. 출력 끝의 「검사하지 못한 항목」을 확인한다.
   - 검사 항목: 술 거래(증정·무료·쿠폰), 술 광고 표시(할인·증정·무제한, 음주 권유, 건강 효과 — 국민건강증진법 제8조의2 제2항 제1·2·5호, F075), 술 혜택 안에 F075 언급, 최초·최저가, 노키즈, 일률적 환불 불가, 리뷰 삭제 조건, 투표 인증 할인, 복권 경품, 참고한 사례의 안전운영조건 빠짐, 원가율·본전·할인율·1회 원가 숫자가 계산 결과에 있는지.
   - 면제는 둘뿐: ① 제목에 「원안」이 든 안(불가 원안을 보여 주는 안)의 설명 줄(단, 「알리는 문구」 줄은 그대로 검사) ② 참고 묶음의 안전운영조건 원문과 같은 줄.
6. 경고가 있으면 생성 모델에 경고 목록을 주고 그 안만 다시 쓰게 한다.
7. **검사 자체의 시험**: `python3 scripts/selftest_check_plan.py` — 멀쩡한 행사안에 문제 문구를 일부러 넣은 고장 사본 10종 + 참고 묶음 없이 돌린 경우를 매번 새로 만들어 돌려, 검사가 실제로 잡는지 확인한다(결과는 reports/시험_이력.csv). pack.sh가 매번 돌리고 어긋나면 멈춘다.

## 술이 나오는 안 (생성문 v4)
거래(국세청: 술 공짜·덤·쿠폰 금지, 값을 받는 판매는 가능)와 알리는 표시(국민건강증진법 제8조의2 제2항: 술 광고에 경품·금품 제공 내용 금지)를 따로 판단한다. 행사안에는 「거래 조건」과 「알리는 문구(술 할인·증정 없이)」를 나눠 적는다. 술 가격은 메뉴판·가격표에만 적는다. 시험 결과는 reports/회차보고_17.md.

## 알려진 한계
- 간단판 시험은 가게마다 3~5안만 만들었다(생성문은 성격마다 3안). 실제 생성 모델이 아니라 사람이 쓴 시험 행사안이다.
- 사례 389처럼 불가 원안을 보여 줄 때는 제목에 「원안」을 넣어야 검사가 설명 줄을 면제한다.

## 캘린더 파일 넣기 (지식 달력 jisik-dates CSV)
`python3 scripts/import_calendar.py <jisik-dates csv>` → 생성/캘린더.csv. 공휴일·명절·국가기념일·○○데이·시험·세무·절기만 옮기고 외국·일본·세계 기념일은 뺀다. trust가 law/agency면 「확정」, 그 밖은 「예정」. 출처가 빈 항목(○○데이 318건 등)은 참고 묶음에서 쓰지 않는다. 공무원 보수 지급일·민간 급여일은 이 파일에 아직 없다(달력 창에서 작업 중).
