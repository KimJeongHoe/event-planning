# 판 8 제안 (2026-11-04)

## 1. 판 7 제안 3개 — 진행 여부와 드는 양

드는 양은 이 작업 방식 기준(한 회차 = 새 창 하나, 응답당 다시 읽는 양 25만 안쪽)으로 어림한 것입니다.

| 제안 | 권하는 결정 | 방식 | 드는 양 | 막히는 점·위험 |
|---|---|---|---|---|
| 쿠폰 QR 사용 처리 | **진행(방식 바꿔서)** | 화면 안에서 카메라로 읽는 방식은 쓰지 않음(아티팩트에 카메라 기능이 없고, 브라우저 카메라 허용도 막힐 수 있음). 대신 인쇄 쿠폰에 「이 화면 주소 + 쿠폰 번호」를 담은 QR을 찍고, 사장님이 휴대폰 기본 카메라로 찍으면 이 화면이 그 번호로 열려 「사용 처리」 단추 하나만 누르게 함. 손님이 같은 QR을 열어도 사장님 개인 저장소라 손님 화면에는 아무 기록도 보이거나 바뀌지 않음 | 작음~중간: QR 그리기 라이브러리 1개(고정 판), 주소 해석, 인쇄물 QR, 점검. 한 회차의 약 3분의 1 | 사장님이 휴대폰에서도 같은 계정으로 로그인해 있어야 함(판 8에서 고친 계정 저장소가 전제). 쿠폰 번호를 손님이 바꿔 적는 위조는 번호에 확인 글자를 넣어 막음 |
| 업종별 평균과 내 결과 나란히 보기 | **보류** (대신 「내 지난 행사끼리 비교」를 먼저) | 다른 가게 결과를 모으려면 공유 저장소에 익명 결과를 모아야 함. 업종별로 10곳 이상 모이기 전에는 평균을 보여 주지 않는 규칙이 필요 | 큼: 공유 저장 규칙, 참여 동의 문안, 익명 처리, 표본 기준, 이상값 거르기. 한 회차 이상 + 배포 뒤 자료가 쌓일 시간 | 「출처에 없는 숫자 금지」 원칙과 부딪힘(공식 통계에 행사 효과 평균이 없음). 가게 매출은 영업 비밀이라 참여 동의가 필요. 배포 전에는 모을 자료가 없음 |
| 배달앱별 리뷰 이벤트 문구 | **원문이 확인된 앱만 진행** | 앱별 운영정책 원문에서 확인된 조건만 문구·검사에 넣고, 확인 못 한 앱은 지금처럼 「확인 필요」와 공통 문구(별점 조건 없음, 대가 표시) | 작음: 앱마다 문구 1종 + 검사 규칙 몇 개. 회차의 일부 | 배민 사장님광장이 막혀 있음(우회 금지). 정책이 자주 바뀌어 확인일을 함께 적고 주기적 재확인이 필요 — 이번 재확인 결과는 「된 것 / 안 된 것」 표 참고 |

## 2. 업종 범위 — 몇 단계로, 어느 업종까지 (결정 필요)
근거: reports/업종조사_A.json·업종조사_B.json(업종 24개, 법 근거 92건 — 확인함 81·확인 필요 11), 사례 DB 업종별 건수. 가게 수는 공식 파일을 다 세지 못해 「확인 필요」.

| 단계 | 업종 | 응용 예시 수(업종 × 시점 5) | 방식 | 이유 |
|---|---|---|---|---|
| 1차(끝남) | 고깃집·카페·미용실·치킨호프 | 60 | 행사형 | 기존 |
| **2차(권함)** | 한식·베이커리·떡집·반찬·편의점·슈퍼·의류·잡화·꽃집·세탁소 | 35 | 행사형 + 업종 ⚠ | 쿠폰·도장·문자·개업 행사가 그대로 통하고 법 위험 낮음~중간, 사례 있음 |
| 3차 | 정육점·화장품 판매점·사진관·세차·정비·PC방·보드게임·숙박·네일·피부관리·헬스·필라테스·반려 미용·용품 | 45 | 행사형 + 업종 전용 질문 칸(담배 판매·영업 종류·성인 확인 등) | 업종 고유 규칙이 화면 칸을 바꿔야 함. 숙박은 시점을 성수기·주말로 바꾼 별도 틀 |
| 4차 | 학원·교습소·태권도장·병의원·치과·한의원·약국·동물병원·공인중개사·휴대폰 판매점·노래연습장·오락실 | 24(시점 3) ~ 40 | **행사 대신 안내형**: 가격 할인·경품 대신 게시표 정비·설명회·건강 강좌·안내문 | 할인·경품·유인 자체가 법으로 막히거나(의료법 환자 유인·약사법 경품·학원 교습비 게시·중개보수·노래방 술) 해석이 많이 남음 |

판 8 화면은 이미 24개 업종 모두에 ⚠ 띠·근거 조문을 붙였으므로, 단계는 「응용 예시를 어디까지 만들지」만 정하면 됩니다.

## 3. 요식업 기준이라 다른 업종에서 어색한 곳
| 곳 | 어색한 점 | 판 8 처리 |
|---|---|---|
| 1단계 「술 판매」 칸 | 학원·병의원·미용에는 맞지 않음 | 업종 자료에서 술=아니오인 업종은 숨김(노래방·편의점은 남김 — 금지·제한 경고를 띄우려고) |
| 원가 탭 「주력 메뉴 원가율」 | 미용·학원·헬스는 재료 원가보다 인건비·시간이 큼 | 이름표를 「주력 시술/강좌/이용권 원가율」로 바꿈. 인건비 칸은 아직 없음(4절 제안 3) |
| 쿠폰 예시 「사이드 1접시 증정」, 「1인·1테이블 1장」 | 음식점 말 | 업종별 예시로 바꾸고 「1인 1장」으로 |
| 개업 순서표의 고깃집 대체 | 학원·소매도 고깃집 예시 | 요식업에만 고깃집 대체, 다른 업종은 비워 두고 이유 표시 |
| 배달앱 실수령 도구 | 학원·병원·미용엔 해당 없음 | 「이 업종은 배달앱 판매가 드뭅니다」 안내 |
| 단계 「신메뉴」, 목표 「포장배달」「신메뉴알리기」「회전율」 | 음식점 말(학원은 새 강좌, 미용은 새 시술, 소매는 신상품) | **남음** — 고르는 값이 사례 자료 분류와 이어져 있어 이름만 바꾸면 거르기가 깨짐. 다음 판에 「보이는 이름」만 업종별로 바꾸는 표를 둘 것 |
| 리뷰 안내문 「맛·서비스는 느낀 대로」 | 음식점 말 | **남음** — 업종별 문구표 필요 |
| 채널 「배달앱 가게 공지」 기본 선택 | 학원·병원엔 없음 | **남음** — 업종별 기본 채널표 필요 |
| 문자 인사말 샘플 | 거래처·음식점 말투가 많음 | **남음** — 업종 꼬리표로 거르기 필요 |
| 병의원·약국·학원에서 「할인」 중심 행사안 | 행사 자체가 위험 | ⚠ 띠·도구 경고로 표시. 근본 해결은 4차 「안내형」 |
| 숙박의 시점(오픈전…위기회복) | 숙박은 성수기·주말이 중심 | **남음** — 3차 때 별도 틀 |
| 화면 업종 6개 묶음 | 「병의원·약국」 안에 안경원·동물병원, 「서비스업」 안에 헬스·숙박·정비가 섞임 | 세부 업종 낱말로 24개 업종 자료를 고르게 함. 업종 칸을 나누는 것은 4절 제안 5 |

## 4. 배포 전에 더 하면 좋은 것(빠진 기능·아이디어·콘텐츠)
1. 업종별 「보이는 이름」 표(단계·목표·채널·리뷰 문구) — 위 「남음」 4곳을 한 번에 해결
2. 쿠폰 QR 사용 처리(위 1번 표, 방식 바꿔 진행)
3. 원가 탭에 인건비·시간 칸(서비스 업종용 본전 계산)
4. 업종별 「하면 안 되는 행사」 자동 거르기 — 지금은 경고만, 병의원·약국은 할인 행사 카드를 뒤로 보내거나 「안내형」 카드로 바꾸기
5. 업종 칸 세분(병의원·약국 → 병의원/약국/안경원/동물병원 등)
6. 배민 「리뷰관리정책」·쿠팡이츠·요기요 정책은 사용자가 원문(PDF·화면 캡처)을 받아 주면 반영
7. 「확인 필요」 11+2건을 공식 질의 문안으로 묶기(참가비 추첨·무료 쿠폰·학원 경품·보드게임카페 영업 분류 등)
8. 점검용 기록 res_check8은 사용자가 화면에서 보인 것을 확인한 뒤 지우기
