## 배포 전에 먼저 제안 — 빠진 기능·아이디어·콘텐츠
1. **실제 생성 모델로 시험**: 지금 시험 행사안은 제가 쓴 것. 생성 모델에 생성문 v4 + 참고 묶음 + 계산 결과를 주고 3가게를 뽑아 검사와 사장님 눈높이 읽기(쉬운 말·길이)를 확인.
2. **개발원 해석 원문 확보**: 한국건강증진개발원의 「주류 할인·증정·쿠폰·캐시백 광고」 안내 문서를 사용자가 받아 주시면 F075·사례 57건의 근거수준을 올리고 질의 문안 질문 가를 줄임.
3. **캘린더 연동 확인**: 사용자가 캘린더 DB 확인을 알려 주면 생성/캘린더.csv 읽기를 실제 파일로 시험하고, 행사안 속 날짜가 달력 파일에 있는지 검사 추가.
4. **업종별 참고 묶음 더 만들기**(원래 제안 4): 학원·소매·병의원 묶음과 요식업 정착기 묶음을 미리 만들고 각각 간단판 시험.
5. **가게별 행사 이력 저장 칸**(원래 제안 5).
6. **배달앱·네이버 플레이스 문구 모음**: 술이 나오는 가게의 배달앱 소개·쿠폰 문구에서 술 표시를 어디까지 쓸 수 있는지 한 장(F075 기반, 공식 해석 대기).
7. **출처 거슬러 확인 + 기준일 장부**(외부 제안 ④⑤): 한 회차에 묶어 처리.
