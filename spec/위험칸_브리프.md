# 위험 칸 채우기 브리프 (회차 4, 2026-11-02)

입력: `risk_packets/risk_N.jsonl` (한 줄에 사례 1건, 위험 4칸 중 빈 칸이 있는 사례). 출력: `risk_results/risk_N.jsonl`.

## 할 일
빈 위험 칸만 채운다(이미 채워진 칸은 건드리지 않음). 칸: legal_risk(⚠법·규정), business_risk(⚠사업), ops_risk(⚠운영), reputation_risk(⚠평판).
- 사례의 업종·조건·혜택·연출·대상·방식에 맞춰 구체적으로 1~2문장. "주의 필요" 같은 뭉뚱그린 말 금지. 같은 문장 복사 반복 금지.
- 위험이 정말 없으면 `없음(이유)` — 예: `없음(무료 정보 제공만 있고 원가·인력 추가 없음)`. 빈칸으로 두지 않는다.
- **legal_risk는 법령 원문에서 확인한 조항만** 적는다: `python3 -I scripts/art.py "<law_src 파일이름 일부>" <조>`로 직접 열어 본 조항. 법령명(제N조 제M항 제K호) + 이유. 확실하지 않으면 `확인 필요(무엇이 불확실한지)`. 원문을 열지 않은 조항 번호는 쓰지 않는다. 별표 수치(과태료 금액표 등)는 `확인 필요`.
  - 자주 쓰는 확인된 조항(그래도 사례마다 맞는지 판단): 표시광고법 제3조 제1항 제1·2호, 제5조; 여신전문금융업법 제19조 제1·4항; 주류 거래질서 확립에 관한 명령위임 고시 제3조 제1항 제2·3호(일반음식점은 주류면허법 제5조 제2항 제2호·시행령 제9조 제5항 제2호로 판매업면허 의제, 과태료 법 제38조 제1항 제4호); 청소년 보호법 제28조; 정보통신망법 제50조; 개인정보 보호법 제15·22조; 옥외광고물법 제3조·제20조 제1항 제1호; 경범죄 처벌법 제3조 제1항 제9·21호; 도로법 제61조; 식품 등의 표시ㆍ광고에 관한 법률 제8조 제1항; 의료법 제27조 제3항·제56조; 약사법 시행규칙 제44조 제1항 제2호; 소득세법 제21조 제1항 제2호·제84조·제129조; 학원법 시행령 제18조; 체육시설법 제27·29조; 동물보호법 제10조 제5항 제3호; 상법 제42조.
  - 해외 사례는 "한국에서 따라 할 때"의 위험으로 적는다.
  - FAQ와 겹치면 FAQ 번호를 이유에 적어도 된다(merged/FAQ.csv).
- 사업 위험: 원가 폭탄, 가격 인식 하락, 행사 뒤 이탈, 단골 역차별, 재고 등. 운영 위험: 주방·인력 과부하, 대기, 재료 부족, 직원 혼선, 정산. 평판 위험: 미끼·조건 숨김 논란, 리뷰 조작 의심, 착한 척 논란, 차별 논란 등.

## 출력 형식 (한 줄에 사례 1건, 입력과 같은 순서·같은 줄 수)
{"case":"<orig_id>","edits":[{"field":"ops_risk","after":"…"},{"field":"legal_risk","after":"…","laws_checked":"표시광고법 제3조"}]}
- 10건마다 append 저장. 끝에 줄 수·json.loads 검증, 그리고 모든 입력 사례의 빈 위험 칸이 채워졌는지 검사.
- 개인 작업 파일은 scratchpad 하위 폴더(브리프 받은 폴더)만 쓴다. 웹 검색 쓰지 않음.

## 최종 보고(짧게)
채운 칸 수(칸별), `없음(이유)` 수, `확인 필요` 수, 새로 원문 확인한 조항 목록.
