# 조건 칸 보강 브리프 (회차 6)
입력 `cond_packets/cond_N.jsonl`(조건 칸이 빈 사례) → 출력 `cond_results/cond_N.jsonl`. 빈 condition(혜택을 받는 조건: 결제금액·인원·메뉴·시간대·요일·인증·대상 자격·예약·선착순 등)만 채운다.
- 실제 사례: 원문에 있는 조건만. 출처 본문은 `src_cache/<md5앞12자>.txt` 또는 `/tmp/claude-0/-home-user/9b7137bb-80cc-5ef4-adb4-73711cbdc18f/scratchpad/cur/<md5앞12자>.txt`(오늘 다시 받은 본문), 없으면 `python3 -I scripts/fetchtext.py "<URL>" 8000`. md5: `python3 -I -c "import hashlib,sys;print(hashlib.md5(sys.argv[1].encode()).hexdigest()[:12])" "<URL>"`. 원문에 조건이 없으면 `원문에 조건 언급 없음`, 못 열면 `원문 확인 불가(이유)`. 조건 없이 누구에게나 주는 경우는 `조건 없음(누구나 — 원문 근거)`. 지어내지 않는다, 막힌 곳 우회 금지.
- 응용 사례: `제안: …`(원가·위험 고려한 조건).
- 성격상 조건이 없는 사례(처분·법령·논란·정책): `해당없음(이유)`.
- 원문과 다른 사실을 보면 "flag"에 적는다(사실 칸 고치지 않음).
출력 한 줄: {"case":"<orig_id>","edits":[{"field":"condition","after":"…"}],"flag":""}. 같은 순서·줄 수, 10건마다 저장, json.loads 검증. 웹 검색 쓰지 않음.
최종 보고: 원문에서 찾음 / 원문에 조건 언급 없음 / 조건 없음 / 원문 확인 불가 / 제안 / 해당없음 수, flag 목록.
