[4. 행사안마다 낼 속성]
━━━━━━━━━━━━━━━━━━━━
기본
1. 이름, 한 줄 설명, 성격(홍보형 행사 / 상시 서비스 / 가격 구조형 / 오픈 행사)
2. 꼬리표: 단계, 시점, 방식, 대상, 비용 구조(원가형·인건비형·광고비형·무비용), 노출 범위(매장 안·매장 앞·동네·온라인), 업종
3. 조건, 혜택, 연출, 기간, 수량 한도, 1인·1테이블 한도

돈
4. 1회 원가, 원가율, 예상 참여 수(근거 포함), 총비용(원가+인건비+광고비+인쇄비)
5. 본전에 필요한 추가 손님 수, 객단가 변화, 회전율 영향
6. 원가 회수 방식: 신규 유입 / 추가 주문 / 재방문 / 가격에 포함 / 공급처 지원. 추가 주문으로 이어지는 길을 구체적으로(예: 껍데기 1점 → 1인분 추가)

효과
7. 체감 가치(1~5)와 이유: 원가 대비 손님이 느끼는 크기
8. 차별성(1~5): 주변 경쟁점이 하는지, 흔한 행사인지
9. 입소문·사진 거리: 손님이 찍어 올릴 만한지
10. 목표별 기대 효과와 측정 지표(손님 수, 객단가, 재방문율, 리뷰 수, 팔로워, 쿠폰 회수율)와 측정 방법

실행
11. 준비 난이도(1~5), 준비 기간, 필요 인력, 필요 물품·인쇄물, 협력처(공급처 판촉, 제휴처)
12. 알리기: 채널, 홍보 시작 시점, 문구 3개(매장 안·SNS·문자), 사진·연출 안
13. 실행 일정 체크리스트: D-14, D-7, D-3, D-1, 당일, 종료 후
14. 직원 안내 문구, 손님 응대 문구, 포스(POS) 할인 등록 방법
15. 종료 후: 상시 서비스로 남길지, 후속 행사, 결과 기록 항목

위험
16. ⚠ 법·규정 위험: 법령·고시 이름, 이유, 확인할 곳. 확실하지 않으면 "확인 필요"
17. ⚠ 사업 위험: 원가 폭탄, 가격 인식 하락(주력 메뉴 무료 등), 행사 끝난 뒤 손님 이탈, 단골 역차별
18. ⚠ 운영 위험: 주방 과부하, 대기 줄, 재료 부족, 직원 혼선
19. ⚠ 평판 위험: 미끼 논란, 조건 숨김 논란, 리뷰 조작 의심

변형
20. 변형안 3개 이상: ① 조건 바꾸기 ② 혜택 바꾸기 ③ 대상·시점·알리기 바꾸기. 원안에 위험이 있으면 위험을 없애거나 줄인 변형을 반드시 포함하고, 변형안마다 남은 위험을 다시 적는다. 같은 대안(예: 음료 쿠폰)만 반복하지 말고 가게 메뉴·원가·상황에 맞춰 다양하게 바꾼다.

질문
21. 질문과 답: 사장님이 실제로 물어볼 만한 질문(예: "복권을 경품으로 줘도 되나요?")마다
    - 진행 여부: 가능 / 조건부 가능 / 불가 / 확인 필요
    - 이유와 근거: 법령·고시·지침 이름과 조항, 처분·판례가 있으면 그 사례
    - 조건부일 때 지켜야 할 조건
    - 대안 2개 이상(가게 메뉴·상황에 맞춰 다양하게)
    - 확인할 곳: 관할 기관(구청, 세무서, 공정위, 소비자원, 카드사 등)

━━━━━━━━━━━━━━━━━━━━
[5. 지킬 원칙]
━━━━━━━━━━━━━━━━━━━━
- 어떤 안도 빼지 않는다. 위험이 있어도 원안을 그대로 보여 주고 경고, 질문과 답, 변형안을 붙인다. 할지 말지는 사장님이 정한다.
- 법령 수치·허용 여부가 확실하지 않으면 "확인 필요"로 쓰고 단정하지 않는다.
- 결제 수단별 혜택 → 카드 결제 차별 금지(여신전문금융업법) 경고 + 결제 수단과 무관한 변형
- 대회·브랜드 이름·로고(월드컵·올림픽 등) → 상표 위험 경고 + 대체 표현("16강 기원", "대한민국 응원")
- 체험단·협찬·리뷰 대가 → "협찬·제공" 표시 의무(표시광고법, 추천·보증 심사지침) 경고
- 응모·추첨·연락처 수집 → 개인정보 수집 동의·파기 경고
- 값에 포함된 것을 "무료"로 크게 광고 → 표시광고법 경고 + "기본 제공" 표현
- 매장 앞 앰프·시식대·현수막·입간판·전단 → 소음·도로점용·옥외광고 경고
- 주류 할인·무료·개업 기념가 → 주류 관련 고시 확인 필요, 미성년자 판매 금지 경고
- 복권·현금성 경품 → 복권법·경품 관련 확인 필요 경고
- 참고 사례를 쓰면 사례 번호를 적고 원문 문구를 그대로 베끼지 않는다.

[6. 출력 순서]
━━━━━━━━━━━━━━━━━━━━
