# 별표 대조 브리프 (회차 6)

국가법령정보센터 별표 원문(PDF→텍스트)을 `law_src/별표/<법령명>__별표<N>.txt`로 받아 두었다(목록: spec/별표_목록.txt, 첫 줄에 원문 PDF 주소). 없는 별표는 `python3 -I scripts/bylfetch.py list "<law_src 파일이름 일부>"`로 목록을 보고 `python3 -I scripts/bylfetch.py get "<이름 일부>" <번호>`로 받는다(법령·고시 모두 가능. 해당 법령 본문이 law_src에 없으면 먼저 `python3 -I scripts/lawfetch.py law_src 법령|행정규칙 "<이름>"`). 별표 텍스트는 grep으로 필요한 부분만 본다. 표가 깨져 수치를 확정할 수 없으면 '확인 필요'를 유지하고 사유를 `별표 수치(표 판독 불가: 별표명)`로 적는다.

## 사례 (입력 byl_packets/byl_N.jsonl → 출력 byl_results/byl_N.jsonl)
- legal_risk의 '확인 필요(별표 …)' 부분을 별표 원문으로 확인해 다시 쓴다: "법령명 [별표 N] 제목 해당 항목: 수치·기준 요약". 확인되면 그 부분 '확인 필요' 삭제. 해소되면 legal_todo "", 다른 이유가 남으면 그 사유(적용 해석 등).
- 출력 한 줄: {"case":"<orig_id>","edits":[{"field":"legal_risk","after":"…","laws_checked":"식품위생법 시행규칙 [별표 17] 제7호 …"},{"field":"legal_todo","after":""}]}
## FAQ (입력 merged/FAQ.csv 의 비고에 '별표 수치'가 있는 문항 → 출력 faq_results/faq_byl.jsonl)
- 해당 칸(reason·conditions·notes·laws)을 별표 원문으로 고친다. 출력 한 줄: {"faq_id":"F0xx","edits":[{"field":"reason","after":"…","laws_checked":"…"},{"field":"notes","after":"…"}]} (바꿀 칸만, after는 칸 전체 새 값). notes 끝의 "[확인 필요 사유: …]"에서 해소된 사유는 지운다.
공통: 원문을 열어 본 별표만 인용. 10건마다 저장, 끝에 json.loads 검증. 웹 검색 쓰지 않음.
최종 보고: 해소 칸 수, 남은 칸 사유별, 새로 받은 별표, 판독 불가 별표.
