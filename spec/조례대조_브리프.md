# 지자체 조례 대조 브리프 (회차 7, 회차 8 재사용: 입력 legal_packets/ordin8.jsonl → 출력 legal_results/ordin8.jsonl, FAQ 패치는 faq_results/faq_ordin8.jsonl)
입력 legal_packets/ordin.jsonl(법 칸 사유가 '지자체 조례'인 사례) → 출력 legal_results/ordin.jsonl. 그리고 merged/FAQ.csv 비고에 '지자체 조례'가 있는 문항 → faq_results/faq_ordin.jsonl(apply_faq 패치 형식, after는 칸 전체 새 값).
- 조례 원문 받기: `python3 -I scripts/lawfetch.py law_src/조례 자치법규 "<정확한 조례 이름>"` (예: "서울특별시 옥외광고물 등의 관리와 옥외광고산업 진흥에 관한 조례"). 이름이 틀리면 '실패' — WebSearch(site law.go.kr 또는 elis.go.kr)로 정확한 이름을 찾는다. 조례 별표는 `scripts/bylfetch.py`가 law_src 본문 파일 기준이라 조례 파일을 law_src에 임시 복사하지 말고, 필요하면 조례 본문의 해당 조문만 인용한다(별표는 '별표 수치'로 남김).
- 사례 지역이 정해져 있으면 그 지자체 조례, 지역이 없거나 해외면 **대표 예시**(서울특별시 + 사례 업종이 많은 광역·기초 1곳)를 원문으로 확인해 "예: 서울특별시 ○○ 조례 제N조: … (지자체마다 다름)"으로 적는다. 사례 지역 조례를 확인하면 legal_todo "", 대표 예시만 확인했으면 legal_todo는 '지자체 조례' 유지하되 legal_risk에 확인한 예시 조문을 적는다.
- 원문을 연 조례만 인용. 출력 한 줄: {"case":"<orig_id>","edits":[{"field":"legal_risk","after":"…","laws_checked":"서울특별시 … 조례 제N조"},{"field":"legal_todo","after":"…"}]}
- 웹 검색 25회 이내, 막힌 곳 우회 금지. 최종 보고: 받은 조례 목록, 해소/예시만 확인/남은 수.
