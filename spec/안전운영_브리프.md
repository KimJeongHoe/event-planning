# 안전운영조건 붙이기 브리프 (회차 8)
입력: `legal_packets/safeops8.jsonl` — 법확인필요사유(legal_todo)가 남았는데 법 칸에 '안전한 운영:' 문구가 없는 사례.
할 일: 사례마다 법 칸 끝에 `[회차8 안전한 운영: …]`(merge.py가 "안전한 운영:" 뒤를 뽑으므로 이 형식을 지킴, 조건 안에 대괄호 쓰지 않기) 한 덩어리를 덧붙인다. 생성 도구가 행사안에 그대로 붙일 조건이다.
- 남은 '확인 필요' 쟁점을 법 칸에서 읽고, 그 쟁점이 풀리지 않아도 위험을 줄일 수 있는 **구체 조건**(금액·대상·문구·절차·확인처)을 1~3개 쓴다. 예: "응모비를 받지 않고 구매 고객 전원 대상 추첨으로", "행사 전 관할 구청 위생과에 전화로 신고 대상 여부 확인 후 진행", "가격표에 부가세 포함 최종가만 표시".
- 사유별: 사실관계 불명 → 그 사실을 확인하는 절차(예: "계약서의 ○○ 조항 확인 후"), 해외 법 → "한국에서 따라 할 때" 기준의 조건, 법령 원문 없음 → 원문이 없어도 안전한 쪽 조건, 지자체 조례 → "관할 시·군·구 ○○과 확인 후" + 일반적으로 안전한 방법.
- 새 법 근거를 지어내지 않는다. 조문을 새로 인용하려면 `python3 scripts/art.py`로 law_src 원문을 확인한 것만. 웹 검색 쓰지 않음.
- 출력: `legal_results/safeops8.jsonl`, 한 줄에 사례 하나 `{"case":"<orig_id>","edits":[{"field":"legal_risk","after":"<기존 전체 값 + 덧붙인 덩어리>"}]}`. legal_todo는 바꾸지 않는다. 20건마다 저장, json.loads 검증. raw는 고치지 않는다.
