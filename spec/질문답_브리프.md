# 사례별 질문과 답 보강 브리프 (회차 7)
입력 qna_packets/q_N.jsonl(case_qna 빈 사례) → 출력 qna_results/q_N.jsonl. 빈 case_qna만 채운다.
- 형식: `Q: … / 진행여부: 가능|조건부 가능|불가|확인 필요 / 근거: … / 조건: … / 대안: ①… ②… / 확인할 곳: …`
- 질문은 이 사례를 따라 하려는 사장님이 실제로 물을 만한 것 1개(사례의 가장 큰 위험·애매한 점). 이미 연결된 FAQ(faq_ids, merged/FAQ.csv)와 같은 질문이면 그 FAQ 답을 이 사례 상황에 맞게 조건·대안만 고쳐 쓰고 근거에 'F0xx 참고'.
- 근거는 사례의 legal_risk에 이미 원문 확인된 조항, 또는 law_src·law_src/별표 원문에서 직접 연 조항만. 불확실하면 '확인 필요'. 대안은 2개 이상, 사례마다 다르게(음료 쿠폰 반복 금지).
- 출력 한 줄: {"case":"<orig_id>","edits":[{"field":"case_qna","after":"…"}]}. 같은 순서·줄 수, 10건마다 저장, json.loads 검증. 웹 검색 쓰지 않음.
최종 보고: 채운 수, 진행여부 분포, 새로 연 조항.
