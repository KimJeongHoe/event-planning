## 1. 방법
- WebSearch 8회만 사용(40회 한도). 대신 **신문사 자체 기사 검색**을 curl로 직접 조회(우회 아님, 각 사이트의 공개 검색 페이지):
  - 매일신문: POST https://search.imaeil.com/RSA/front_new/Search.jsp (qt, sDate/eDate=yyyymmdd, sPeriod=manually, menu=뉴스, st=페이지) — 1990년대 기사까지 열람 가능, 가장 생산적.
  - 경향신문: https://search.khan.co.kr/?q=..&media=khan&term=5&startDate=19900101&endDate=20091231 — 1999년 이후 기사 위주.
  - 한겨레: https://search.hani.co.kr/search/newslist?searchword=..&startdate=..&enddate=.. — 2000년대 결과 적음, 페이지 파라미터 미작동. (WebSearch allowed_domains에 hani.co.kr 넣으면 API 400 오류)
  - 한국일보: 사이트 검색은 JS라 WebSearch(allowed_domains=hankookilbo.com)로 1990년대 URL을 찾고 본문은 fetchtext로 열람.
- 본문은 모두 `python3 -I scripts/fetchtext.py <URL>`로 열어 확인(응답 200). 원문 캐시는 스크래치패드에만 저장.
- 검색 도우미 스크립트(스크래치패드, 커밋 안 함): hs.py(한겨레), ks.py(경향), ms.py(매일), body.py/mbody.py(본문 추출).
