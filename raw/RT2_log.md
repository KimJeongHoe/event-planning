## 1. 방법
- WebSearch 4회만 사용(한도 40). 나머지는 각 신문사의 **공개 사이트 검색**을 curl로 직접 조회(우회 아님).
  - 부산일보: POST https://search.busan.com/openSearch/totalSearch (query, sfield=TITLE,CONTENTS, sort=DATE/DESC, startCount, listCount, startDate/endDate=yyyymmdd) — 1989년 기사부터 텍스트 열람 가능. 이번에 가장 생산적(23건 출처).
  - 매일신문: RET와 같은 Search.jsp. 기간을 1988~1996, 1990~2001로 좁혀 새 검색어 사용.
  - 경인일보: https://www.kyeongin.com/search?query=..&page=..&sort=R — 1999년 이후 텍스트 기사(article/번호). 그 이전은 지면 PDF 이미지(pdf.kyeongin.com)라 본문 텍스트 없음 → 사용 안 함. search/news 경로에 날짜 파라미터를 넣으면 결과 0건.
  - 국제신문: 검색 결과가 iframe https://www.kookje.co.kr/news2011/asp/search_detail.asp?stitle=(cp949 인코딩)&sdate=&edate=&sort=desc — 1995년 기사부터 열람 가능.
  - 한국일보: 사이트 검색 JS → WebSearch(allowed_domains=hankookilbo.com)로 URL 찾고 fetchtext로 본문.
- 본문은 전부 `python3 -I scripts/fetchtext.py <URL>`로 열어 확인(모두 응답 200). 원문 캐시·도우미 스크립트는 스크래치패드 col_rt2/에만 둠(bss.py 부산일보, kys.py 경인, kjs.py 국제, ms.py 매일, mo.sh/bo.sh/ho.sh 본문 열기, gen_a.py/gen_b.py/merge.py 생성·검증).
- 중복 확인: merged/사례DB.jsonl의 source_urls 전체(1,029개)와 대조 → 겹침 0. 이름 grep(화환·약국·피자·주유소·쿠폰북 등)으로 유형 중복 확인, 겹치는 유형은 notes에 기존 번호 표기.
