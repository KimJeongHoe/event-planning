# 행사안(간단판) — 주택가 카페 비수기

※ 생성문 v4 + 참고 묶음(요식업 비수기) + 계산 결과(시험_카페)로 만든 시험 행사안. 숫자(원가율·본전·할인율·1회 원가)는 계산 결과의 값만 썼다.
※ 먼저 물을 것: 소상공인 여부(업종·상시 근로자 수·직전 3년 평균매출액) — 모르면 "소상공인이면 …, 아니면 …"으로 두 경우를 적는다. 일회용컵 보증금제 대상 매장인지도 먼저 확인한다.
※ 달력: 날짜 자료 없음(생성/캘린더.csv 없음) — 행사 날짜는 정하지 않았다.

## 안 1. 가격 구조형 — 평일 오후 2~5시 아메리카노+디저트 세트 9,500원
- 한 줄 설명: 한가한 평일 오후 시간대에만 세트를 내어 빈 좌석을 채우는 안
- 조건: 평일 오후 2~5시, 매장 이용 또는 포장, 세트 구성(아메리카노+디저트) 고정
- 혜택: 세트 9,500원 (따로 사면 11,000원)
- 1회 원가: 1,500원 (참여 200명 기준 혜택 총비용 300,000원, 고정비 20,000원 포함 총비용 320,000원, 본전 필요 추가 손님 57명 — 계산 결과 값)
- 진행여부: 조건부 가능 — 시간대·구성·종료일을 매장 안과 SNS에 같은 내용으로 적는다(F044·F045)
- 근거수준: FAQ 근거 따름
- 참고 사례: 187, 148
- 알리는 문구(매장 안·SNS·문자): ① "평일 오후 2~5시, 아메리카노와 디저트 세트 9,500원" ② "한가한 오후, 조용히 쉬어 가세요. 평일 2~5시 세트 9,500원" ③ "오후 세트 시작했어요 (평일 2~5시, 매장 정상가 11,000원)"

## 안 2. 상시 서비스 — 텀블러 지참 500원 할인
- 한 줄 설명: 개인 컵을 가져오면 깎아 주어 단골을 만들고 1회용 컵 사용을 줄이는 상시 안
- 조건: 개인 컵·텀블러 지참 손님, 상시
- 혜택: 음료 500원 할인
- 1회 원가: 500원 (참여 240명 기준 혜택 총비용 120,000원, 고정비 0원, 총비용 120,000원, 본전 필요 추가 손님 22명 — 계산 결과 값)
- 진행여부: 확인 필요 — 안전운영조건(아래)을 지킬 때 조건부 가능
- 근거수준: 조문 해석만(공식 해석 원문 없음)
- 안전운영조건(사례 1526): 매장이 대상인지 관할 지자체·자원순환보증금관리센터에 확인 ／ ① 매장 안에서 먹고 마시는 손님에게는 다회용 컵·그릇·수저를 쓰고, 1회용 컵·빨대·용기는 포장(테이크아웃)·배달 손님에게만 제공 ② 배달앱·키오스크 주문 화면에 '1회용 수저·포크 받지 않기' 같은 선택 항목을 두기 ③ 비닐 봉투·쇼핑백은 무료로 주지 않고(종이 재질은 제외) 필요하면 값을 받고 판매 ④ 일회용컵 보증금제 대상 매장(고시된 프랜차이즈 등)은 음료 1회용 컵에 300원을 포함하고 컵을 돌려받으면 반드시 돌려주며, 대상인지 애매하면 자원순환보증금관리센터·시군구청에 먼저 확인 ⑤ 축제·야시장 부스는 영업신고 형태를 주최 측에 확인하고 다회용기 대여·회수를 기본으로 하며, 개인 컵·다회용기 할인은 할인 금액과 적용 범위(매장 안·포장)
- 참고 사례: 1526
- 알리는 문구: ① "개인 컵을 가져오시면 500원 깎아 드려요" ② "텀블러 가져오면 500원, 매장 안에서는 머그잔으로 드립니다" ③ "내 컵으로 마시는 하루, 500원 할인"

## 안 3. 상시 서비스 — 스탬프 10개 모으면 아메리카노 1잔 서비스
- 한 줄 설명: 비수기에도 다시 오게 만드는 도장 적립 안
- 조건: 음료 1잔당 스탬프 1개, 10개 모으면 아메리카노 1잔, 유효기간 표시
- 혜택: 아메리카노 1잔 서비스
- 1회 원가: 700원 (참여 20명 기준 혜택 총비용 14,000원, 고정비 15,000원 포함 총비용 29,000원, 본전 필요 추가 손님 6명 — 계산 결과 값)
- 진행여부: 조건부 가능 — 쿠폰·도장에 유효기간을 둘 때는 미리 적고 남은 분 환불 기준을 정한다(F027)
- 근거수준: FAQ 근거 따름
- 참고 사례: 628
- 알리는 문구: ① "스탬프 10개를 모으면 아메리카노 한 잔을 드려요" ② "단골 도장판 시작, 10번째는 서비스" ③ "다시 오시는 분께 드리는 작은 선물, 도장 10개"

## 추천 조합 3개와 한 달 달력
- 추천: 안 1 + 안 3 + 안 2 (총비용 합계는 320,000원 + 29,000원 + 120,000원, 계산 결과 값)
- 한 달 달력: 달력 자료 없음 — 캘린더 도구의 목록 파일을 받은 뒤 만든다
